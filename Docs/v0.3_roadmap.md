# V0.3 Roadmap

## Hedef

Anadil V0.3 hedefi:

```text
Dynamic/heterogeneous dizi MVP + native compiler stabilizasyonu
```

V0.2 heap, RC ve dinamik `metin` temelini kurdu. V0.3 bu temel uzerine ilk
koleksiyon tipini ekler: `dizi`.

## Kapanis Durumu

V0.3 dizi MVP kod tarafi buyuk olcude tamamlandi. Kalan is release/RC
hazirligi, dokuman son kontrolu ve temiz paket smoke testidir.

## Tamamlanan Kapsam

- [x] Dizi tip syntax'i: `dizi`.
- [x] Dizi literal syntax'i: `{1, 2, 3}`.
- [x] Bos dizi: `bos: dizi = {}`.
- [x] Index okuma: `a[0]`.
- [x] Index atama: `a[0] = yeni_deger`.
- [x] `uzunluk(dizi)` builtin destegi.
- [x] Dynamic/heterogeneous eleman modeli.
- [x] `sayi`, `mantik`, `metin` elemanlari.
- [x] Nested dizi degerlerinin runtime'da tutulabilmesi.
- [x] Out-of-range index icin runtime hata.
- [x] Negatif index icin runtime hata.
- [x] Parser/AST node'lari.
- [x] Semantic analiz: dizi tipi ve index tipi kontrolleri.
- [x] Interpreter parity.
- [x] Native backend: dizi allocation, index read, index assignment.
- [x] Runtime helper'lari: dizi olustur, get, set, uzunluk.
- [x] RC entegrasyonu: dizi nesnesi, metin/dizi eleman retain/release.
- [x] Dizi parametre, return ve local sharing testleri.
- [x] Native edge testleri.

## Kullaniciya Gorunen Ornek

```ana
Ana() {
    degerler: dizi = {1, "iki", dogru};

    yazdir(uzunluk(degerler));
    yazdir(degerler[0]);

    degerler[0] = "bir";
    yazdir(degerler[0]);
}
```

## Semantik Kararlar

- Diziler referans tiptir.
- `a: dizi = {1}; b: dizi = a;` sonrasi `a` ve `b` ayni dizi nesnesini
  paylasir.
- Dizi elemanlari degistirilebilir.
- Elemanlar heterojen olabilir.
- Dizi elemanlari runtime'da tag/payload olarak tutulur.
- Bounds check runtime'da yapilir.
- Negatif index desteklenmez.
- `yazdir(dizi)` V0.3 kapsaminda yoktur.
- `yazdir(dizi[i])` V0.3 kapsaminda vardir.
- Dizi elemanindan donen dynamic `deger` ile aritmetik/dynamic dispatch V0.3
  kapsaminda yoktur.

## Native Runtime Layout

Dizi data layout'u:

```text
[len: u64][tag0: u64][payload0: u64][tag1: u64][payload1: u64]...
```

Heap header ile tam nesne:

```text
[refcount: u64][tip_id=ANADIL_TIP_DIZI][data...]
```

Runtime tag'leri:

```text
ANADIL_DEGER_SAYI
ANADIL_DEGER_MANTIK
ANADIL_DEGER_METIN
ANADIL_DEGER_DIZI
```
